# Snapchat-inspired design direction

## Visual direction

This app should feel warm, social, and immediate. Think:
- yellow as primary brand accent
- bold typography and rounded corners
- soft shadows and floating cards
- full-bleed hero moments with utility in mind
- frictionless mobile interaction

## Design principles

### 1. The map is the social layer
The map should feel like a private social network, not a generic navigation app.

### 2. Content should feel ephemeral but useful
Use soft gradients, quick interactions, and clear status states. The product should feel alive but not noisy.

### 3. Friend-first, not map-first
Profile cards, chat, friend activity, and status should feel more central than analytics or admin screens.

### 4. Privacy should be emotionally reassuring
Users should understand exactly what is shared and with whom before enabling live location.

```text
Coral alert: #FF6C6C

```

## UI patterns

- Floating nav bars for map, chat, friends, profile
- Card stacks for nearby users, pending requests, and map pins
- Rounded 28px-32px surfaces with subtle shadows
- Large type for core actions like "Share my location"
- Quick toggles for privacy modes and map styles

## Example interface organization

```text
Bottom navigation
  - Friends
  - Map
  - Chat
  - Profile

Top panels
  - Nearby friends
  - Live location banner
  - New request indicator

Floating modals
  - Add friend request
  - Create Gem
  - Create Spot
  - Message thread
```

## Recommended visual mood

- Soft gradients over white and warm gray backgrounds
- Black text on bright surfaces
- Collection cards with large pill labels and minimal clutter
- Strong emphasis on friend activity, presence, and map discovery

## Launch polish checklist

- onboarding clarity
- error and empty states
- loading skeletons
- responsive mobile behavior
- accessible contrast and touch targets
- terms/privacy messaging before sharing live location
